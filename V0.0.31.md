# Changelog V0.0.31

## TTS Installation Refactoring
- **Programmatic Installation:** Refactored the local TTS (Piper) installation process. The script `packages/tts/src/install.ts` now exports a programmatic `runInstall(ttsRoot)` function instead of relying purely on CLI execution.
- **Direct Gateway Integration:** Modified the Gateway TTS route (`packages/core/src/gateway/routes/tts-local.ts`) to call `runInstall` directly as a standard function, eliminating the need to spawn a child process (`Bun.spawn`). Added interception for `console.log` and `console.warn` to correctly capture and stream installation logs to the frontend.
- **Standardized Data Directory:** Standardized the TTS root directory path (`TTS_ROOT`) to use the user's `~/.hive/tts` directory (configurable via `HIVE_TTS_ROOT` or `HIVE_HOME`). This makes the TTS functionality robust across different environments, including local development, Docker, and global NPM installations, replacing the previous fragile relative package paths.
- **Server Path Updates:** Updated `packages/tts/src/server.ts` to use the new standardized `TTS_ROOT` directory layout.

## Docker & Build Updates
- **Package Configuration:** Updated the `Dockerfile` to properly copy and include the `packages/tts` directory (replacing references to `packages/hivelearn`).
- **Install Optimizations:** Added the `--ignore-scripts` flag to `bun install` in the Dockerfile to ensure a clean build without triggering unnecessary or conflicting post-install scripts during the container assembly.

## Cleanup & Migration
- **HiveLearn Extraction:** The `@johpaz/hivelearn` package has been completely extracted and moved to a separate repository.
- **SDK Cleanup:** Removed the legacy `hivelearn` exports (`src/hivelearn/index.ts`) from `@johpaz/hive-sdk` (`packages/sdk/package.json`), decoupling the SDK from the specific hivelearn business logic.
- **Lockfile Synchronization:** Updated `bun.lock` to remove the stale references to the `hivelearn` workspace, fixing the `Workspace dependency "@johpaz/hivelearn" not found` pipeline error.
