# Plan: Replace js-yaml with Bun's native YAML

## Goal
Eliminar la dependencia `js-yaml` y usar el parser nativo de YAML de Bun.

## Pasos

### 1. Actualizar archivos que usan js-yaml

-Cambiar: `import * as yaml from "js-yaml";`

## API de Bun
```ts
import { YAML } from "bun";

const obj = YAML.parse("name: John\nage: 30");
// { name: "John", age: 30 }
```

El parser nativo cubre >90% del spec YAML 1.2 y es adecuado para casos de uso reales.
